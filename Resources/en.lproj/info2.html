On this tab, pick one of the six sample prompts and run the same query twice:

1. Search with index - the query scans the vector index on IndexedVector.
2. Search without index - the same query scans the raw vectors of NonIndexedVector, record by record.

Both lists show the same top matches, ranked by cosine similarity. The Time (ms) fields show how long each query took: on 300,000 texts, the indexed query answers in a few hundred milliseconds while the full scan takes about ten seconds.

The similarity threshold is set to 0.85. With the ruri-v3 model, unrelated texts still score around 0.80, so a lower threshold floods the result with noise - and slows the indexed query down as well.

The prompts are bilingual. Pick the Japanese prompt なぜ人は化粧が好きなのでしょう？ and watch it find English answers: the embedding model is multilingual, so the query language does not have to match the data language.
